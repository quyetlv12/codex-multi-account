## Why

The local Codex LB launcher uses the generic AppleScript icon, making it hard to identify in macOS Applications.

## What Changes

- Add a navy macOS icon using the existing Codex LB terminal mark.
- Retain a reproducible native renderer and a complete ICNS asset.
- Update only the local launcher's icon metadata and resources, with a backup and verification that its executable code and script are unchanged after renewing the signature.

## Impact

No backend, dashboard, account, database, routing or service changes.
